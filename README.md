## 🛠️ Pattern Matrix

| Core Pattern | Primary Trigger / Clue | Target Time Complexity |
| :--- | :--- | :--- |
| **HashMap / Set** | Lookups, frequency counts, tracking seen values | $O(N)$ Space / $O(1)$ Time |
| **Two Pointers** | Sorted arrays, pair/triplet searching, opposite ends | $O(N)$ Time / $O(1)$ Space |
| **Sliding Window** | Contiguous subarrays or substrings meeting a condition | $O(N)$ Time |
| **Prefix Sum** | Range sum queries, running calculations | $O(N)$ Preprocessing / $O(1)$ Query |
| **Monotonic Stack** | Next/Previous Greater or Smaller element queries | $O(N)$ Time |
| **Binary Search** | Monotonic search spaces, "Min-Max" optimization | $O(\log N)$ Time |
| **Topological Sort** | Dependency ordering, prerequisite scheduling | $O(V + E)$ Time |
| **Union Find** | Dynamic connectivity, cycle detection in undirected graphs | $O(\alpha(N))$ Amortized Time |
